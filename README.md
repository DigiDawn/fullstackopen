# Full Stack Open — Part 1 (Exercises 1.1–1.14)

- `part1/courseinfo`: exercises 1.1–1.5 (final version)
- `part1/unicafe`: exercises 1.6–1.11 (final version)
- `part1/anecdotes`: exercises 1.12–1.14 (final version)

Each folder is an independent Vite React application. To run one:

```bash
cd part1/unicafe
npm install
npm run dev
```

Run the same commands in `courseinfo` and `anecdotes` to test them.

Copy `part1/` into your existing Full Stack Open repository. Do not commit `node_modules/`.
Review, test, and understand your work before marking exercises completed in the course submission system.
