# Course Information — Full Stack Open Part 1

Completed exercises **1.1 and 1.2** using React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

## Build

```bash
npm run build
```

The application uses `Header`, `Content`, `Part`, and `Total` components. `App` holds the course data and passes it via props.
